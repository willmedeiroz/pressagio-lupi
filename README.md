# PRESSÁGIO

RPG tático isométrico para o console **Lupi**. Os inimigos anunciam o que vão fazer antes de agir, e você responde no tempo que
sobra: desvia, empurra, mata quem declarou ou usa o terreno. Leve a **Carga** da vila até o rei, trecho a trecho.

- **Jogar no navegador:** https://willmedeiroz.github.io/pressagio-lupi/
- **Baixar para o Lupinho:** [`pressagio.lupi`](https://github.com/willmedeiroz/pressagio-lupi/raw/main/pressagio.lupi), depois
  `lupinho pressagio.lupi`

| Lupi | Teclado (Lupinho) | |
|---|---|---|
| D-pad | W A S D | cursor e navegação |
| A | J | confirma |
| B | K | volta |
| X | L | esperar, no combate |
| L | G | pausa na batalha |

## Este repositório

Aqui fica só o build do jogo: o `pressagio.lupi` (o jogo empacotado para o Lupinho e o console Lupi), o `lupi.yaml` com os dados do
jogo e, no GitHub Pages, a versão web. O desenvolvimento acontece em um repositório privado.
